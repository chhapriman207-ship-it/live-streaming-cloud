📚 Documentation

🎯 Overview

This is a client-side HLS streaming system that works entirely in the browser. It uses local storage to manage stream tokens and provides a secure way to share HLS streams with time-based expiry.

🔑 Key Features

  • ✅ No backend required - runs entirely in browser
  • ✅ Time-based stream expiry
  • ✅ Quality switching (Auto/Manual)
  • ✅ Fullscreen support
  • ✅ Real-time statistics
  • ✅ Local stream management
  • ✅ Shareable stream tokens

🚀 How to Use

Step 1: Generate Stream
Go to Generator tab → Enter your HLS URL → Click Generate

Step 2: Share or Play
Copy the stream URL and share it, or click "Play Stream" to watch immediately

Step 3: Monitor
Track all your generated streams in the "My Streams" tab

🔧 URL Parameters

?play=eyJzdHJlYW1JZCI6Ii4uLiJ9 # Auto-play stream
?tab=player # Open specific tab

⚠️ Important Notes

CORS Limitation: This client-side version cannot bypass CORS restrictions. The source HLS URL must have proper CORS headers configured. For production use with CORS-restricted sources, deploy the full 7-file backend system.

🎓 Supported Formats

  • 📹 HLS (.m3u8) - HTTP Live Streaming
  • 🎬 Adaptive Bitrate Streaming (ABR)
  • 🔊 Audio-only streams
  • 📱 Mobile-optimized playback
